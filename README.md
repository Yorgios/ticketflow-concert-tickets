## Tech stack

HTML5, CSS3 and vanilla JavaScript.

## Project structure

    index.html   -> page layout
    styles.css   -> styles
    app.js       -> application logic
    README.md    -> project documentation

## Git workflow

- No direct commits to `main` (except the Tech Lead's initial commits).
- Every change goes through a branch and a Pull Request.
- Commit messages in English using Conventional Commits (`feat:`, `style:`, `chore:`, `fix:`).

## How to run

Open `index.html` in a browser.
